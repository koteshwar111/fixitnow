# FixItNow – Service Booking Platform

FixItNow is a service booking platform designed to streamline the management of bookings, taskers, categories, and payments through an admin management system.

## Project Overview

The project was developed as a 1-month project by a team of 3 members. I worked as a Backend Developer, focusing on REST API development, CRUD operations, database integration, and service management workflows.

## Key Features

- Booking management
- Tasker management
- Category and sub-category management
- Payment management
- Category-based tasker assignment
- Tasker availability tracking
- Booking workflow management
- Relational database management
- RESTful API integration
- CRUD operations

## Tech Stack

- React.js
- Node.js
- Express.js
- MySQL
- Sequelize ORM
- REST APIs
- Git
